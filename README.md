# MUD Client - Веб-клиент для MUD игр с WebSocket-Telnet прокси

Простой и удобный веб-клиент для подключения к MUD (Multi User Dungeon) серверам через Telnet с использованием WebSocket-Telnet прокси.

## Особенности

- ✅ Модальное окно для ввода адреса сервера и порта при запуске
- ✅ Большое поле для отображения информации от игрового сервера
- ✅ Удобное поле для ввода команд
- ✅ Автоматическая прокрутка логов
- ✅ **Встроенный WebSocket-Telnet прокси** для подключения к любым Telnet-серверам
- ✅ Очистка Telnet контрольных кодов и ANSI цветовых кодов
- ✅ Статус подключения
- ✅ Возможность переподключения
- ✅ Темная тема, удобная для длительных игровых сессий

## Архитектура

```
┌─────────────┐      WebSocket       ┌──────────────┐      TCP/Telnet      ┌──────────────┐
│  Браузер    │ ◄────────────────► │  Прокси-     │ ◄────────────────► │  MUD Сервер  │
│  (Frontend) │     ws://:8080     │  сервер      │     telnet://:4000 │  (Telnet)    │
│             │                    │  (Node.js)   │                    │              │
└─────────────┘                    └──────────────┘                    └──────────────┘
```

Браузеры не поддерживают прямые TCP/Telnet соединения, поэтому используется промежуточный прокси-сервер, который:
1. Принимает WebSocket соединения от браузера
2. Устанавливает TCP/Telnet соединение с целевым MUD сервером
3. Пробрасывает данные в обе стороны

## Установка и запуск

### Требования
- Node.js (версия 16 или выше)
- npm

### Установка зависимостей

```bash
npm install
```

### Запуск прокси-сервера и фронтенда одновременно

```bash
npm run start
```

Эта команда запустит:
- Прокси-сервер на порту 8080 (доступен на всех интерфейсах `0.0.0.0`)
- Frontend приложение на порту 5173 (доступен на всех интерфейсах `0.0.0.0`)

После запуска приложение будет доступно:
- Локально: `http://localhost:5173`
- Из локальной сети: `http://<ВАШ_IP>:5173` (например, `http://192.168.1.100:5173`)

Чтобы узнать ваш IP адрес в локальной сети, выполните:
```bash
hostname -I | awk '{print $1}'
```

### Раздельный запуск

**Терминал 1 - Запуск прокси-сервера:**
```bash
npm run proxy
```

**Терминал 2 - Запуск фронтенда:**
```bash
npm run dev
```

### Сборка для продакшена

```bash
npm run build
npm run preview
```

## Использование

1. Запустите приложение (`npm run start`)
2. Откройте браузер по адресу `http://localhost:5173`
3. Введите адрес MUD сервера (например, `mud.example.com`)
4. Введите порт (обычно от 4000 до 9000)
5. Нажмите "Подключиться"
6. Вводите команды в поле ввода и нажимайте Enter или кнопку "Отправить"

## Примеры MUD серверов для тестирования

- **Discworld MUD**: `discworld.starters-mud.net:4242`
- **Aardwolf**: `aardmud.org:4000`
- **LPMuds**: различные сервера на портах 4000-9000

## Настройка прокси

По умолчанию прокси запускается на порту `8080`. Вы можете изменить порт через переменную окружения:

```bash
PROXY_PORT=9000 npm run proxy
```

## Как это работает

### Frontend (браузер)
1. Пользователь вводит адрес и порт MUD сервера
2. Клиент подключается к локальному прокси через WebSocket: `ws://localhost:8080/?host=<address>&port=<port>`
3. Команды отправляются через WebSocket и автоматически дополняются символом новой строки

### Proxy Server (Node.js)
1. Получает WebSocket соединение с параметрами `host` и `port`
2. Устанавливает TCP соединение с указанным MUD сервером
3. Пробрасывает данные:
   - От MUD → WebSocket (текст в UTF-8)
   - От WebSocket → MUD (команда + `\n`)
4. Обрабатывает ошибки и закрытие соединений

## Безопасность

⚠️ **Важно**: Данный прокси предназначен для локального использования. При размещении в публичном доступе необходимо реализовать:
- Аутентификацию пользователей
- Ограничение списка разрешенных серверов
- Rate limiting
- HTTPS/WSS шифрование
