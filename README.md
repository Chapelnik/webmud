# MUD Client - Веб-клиент для MUD игр

Простой и удобный веб-клиент для подключения к MUD (Multi User Dungeon) серверам.

## Особенности

- ✅ Модальное окно для ввода адреса сервера и порта при запуске
- ✅ Большое поле для отображения информации от игрового сервера
- ✅ Удобное поле для ввода команд
- ✅ Автоматическая прокрутка логов
- ✅ Поддержка WebSocket подключения
- ✅ Очистка Telnet контрольных кодов
- ✅ Статус подключения
- ✅ Возможность переподключения
- ✅ Темная тема, удобная для длительных игровых сессий

## Установка и запуск

### Требования
- Node.js (версия 16 или выше)
- npm

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется в браузере по адресу `http://localhost:3000`

### Сборка для продакшена

```bash
npm run build
```

### Предварительный просмотр сборки

```bash
npm run preview
```

## Использование

1. Откройте приложение в браузере
2. Введите адрес MUD сервера (например, `mud.example.com`)
3. Введите порт (обычно от 4000 до 9000)
4. Нажмите "Подключиться"
5. Вводите команды в поле ввода и нажимайте Enter или кнопку "Отправить"

## Примечание о подключении

Этот клиент использует WebSocket для подключения к серверу. Если ваш MUD сервер работает только по протоколу Telnet, вам понадобится промежуточный сервер (proxy) для конвертации Telnet в WebSocket.

Для тестирования можно использовать публичные MUD серверы с поддержкой WebSocket или поднять локальный тестовый сервер.
